# Atelier Linux : prise en main

Ce dossier accompagne le parcours « Linux, pour de vrai ». Ouvrez un terminal
dans ce dossier, puis suivez les missions dans l'ordre. Les commandes demandées
s'exécutent ici, sans droits administrateur.

Après une mission, lancez `bash verifier.sh 01` (en adaptant le numéro). Le
vérificateur contrôle vos résultats et affiche un code seulement si la mission
est réussie. Pour les missions 31 à 34, il exécute aussi les scripts que vous
avez écrits sur les données d'exercice. Reportez le code sur le site pour
enregistrer votre progression.

Tous les fichiers à modifier ou créer sont dans `travail/` et `reponses/`.
Conservez `donnees/` intact : il sert de point de départ aux exercices.

Les missions 36 à 42 portent sur AlmaLinux et consultent l'état réel de votre
VM (`rpm`, `dnf`, `systemctl`, `journalctl`, `ip`, `ss`, `getenforce`). Elles ne
modifient ni les paquets, ni les services, ni le pare-feu, ni SELinux.

Le site et le vérificateur fonctionnent hors ligne. Si vous souhaitez repartir
de zéro, extrayez simplement une nouvelle copie de l'archive dans un autre
dossier.
